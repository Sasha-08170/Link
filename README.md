
# Эффектные карточки с анимацией и интерактивные ссылки

Описание:
современный минималистичный стиль для веб-страниц с акцентом на читабельность и плавные переходы.
Дизайн построен вокруг карточки с мягкой тенью и живыми ссылками, которые реагируют на действия пользователя.

Особенности:
- Градиентный фон (фиолетово-синий переход)
- Центрированная карточка с округлёнными углами и глубокой тенью
- Плавный hover-эффект подъёма карточки
- Элегантные ссылки с золотым акцентом и анимированным фоном
- Поддержка фокуса для доступности (outline при навигации с клавиатуры)
- Современный шрифт “Inter” с fallback на классический Georgia
- Адаптивность под мобильные устройства
